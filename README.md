# 十九的个人世界

一个使用纯HTML、CSS和JavaScript构建的个人网站，具有流体渐变背景和毛玻璃效果。

## 🌟 特点

- 🎨 流体渐变背景 - 4个动态移动的彩色流体球
- ✨ 毛玻璃效果 - 所有卡片和容器的液态玻璃质感
- 🌙 暗色模式 - 支持明暗主题切换
- 📱 响应式设计 - 完美适配手机、平板和桌面端
- 💬 评论区 - 讨论墙功能
- 🚀 纯静态 - 无需后端，可直接部署

## 📁 文件结构

```
├── index.html          # 首页
├── blog.html           # 分享页面
├── about.html          # 关于页面
├── links.html          # 交友/讨论墙页面
├── styles.css          # 样式文件
├── script.js           # JavaScript文件
├── avatar.jpg          # 头像图片
├── bg.jpg              # 背景图片
├── icon1-transparent.png  # QQ图标
├── icon2-transparent.png  # 邮箱图标
└── icon3-transparent.png  # B站图标
```

## 🚀 部署方式

### GitHub Pages
1. Fork 或克隆此仓库
2. 在仓库设置中启用 GitHub Pages
3. 选择主分支作为源
4. 访问 `https://yourusername.github.io/repository-name`

### Vercel
1. 导入此仓库到 Vercel
2. 自动部署完成

### Netlify
1. 拖拽文件夹到 Netlify
2. 自动部署完成

## 🎨 自定义

### 修改个人信息
编辑 `index.html` 和 `about.html` 中的文字内容。

### 修改头像
替换 `avatar.jpg` 文件。

### 修改联系方式
编辑 `index.html` 中的链接：
- QQ群链接
- 邮箱地址
- B站主页

### 修改背景
替换 `bg.jpg` 文件或调整 `styles.css` 中的背景样式。
